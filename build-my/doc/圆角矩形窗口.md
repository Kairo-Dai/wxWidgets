# 圆角矩形无边框窗口

> 本文在《无边框窗口.md》的基础上，结合 wxWidgets 源码（尤其是 `wxFRAME_SHAPED` / `SetShape()` 的实现以及 `wxRichToolTipPopup` 示例），总结如何在 Linux（X11/Wayland）和 Windows 上创建**圆角矩形 + 无边框**的顶层窗口。

## 1. 需求与思路

目标窗口特性：
- 顶层窗口（`wxFrame` 或 `wxPopupWindow` 派生类）；
- 无系统标题栏、无系统边框、可选是否出现在任务栏；
- 窗口外轮廓是一个带指定半径的**圆角矩形**；
- 需在 Windows + Linux（GTK/X11 为主）上统一行为；
- 在 Wayland 环境下尽可能工作，但接受其局限（详见 5.2）。

整体思路：
1. 用“无边框窗口”的做法创建一个 **可形状化** 的顶层窗口：
   - 边框关闭：`wxBORDER_NONE` / `wxNO_BORDER`；
   - 允许自定义形状：`wxFRAME_SHAPED`；
2. 通过 `wxNonOwnedWindow::SetShape(const wxGraphicsPath&)` 设置一个**圆角矩形路径**，窗口即成为圆角矩形。
3. 在 `OnSize` 中动态重算形状，使圆角能跟随窗口大小变化。

相关源码：
- 圆角路径示例：`src/generic/richtooltipg.cpp` 中 `wxRichToolTipPopup`（`path.AddRoundedRectangle()` / `AddArcToPoint()`）。
- 形状基础设施：`include/wx/nonownedwnd.h`、`src/msw/nonownedwnd.cpp`、`src/gtk/nonownedwnd.cpp`。
- 无边框基础：见 `build-my/doc/无边框窗口.md`。

## 2. 样式与创建

### 2.1 推荐样式组合

以 `wxFrame` 为例：

```cpp
static long GetRoundedBorderlessStyle()
{
    long style = 0;

    style |= wxFRAME_SHAPED;   // 允许 SetShape()
    style |= wxBORDER_NONE;    // 不要普通边框（GTK/MSW 都会去掉 WM 装饰）

    // 可选：不在任务栏显示、置顶
    style |= wxFRAME_NO_TASKBAR;  // 工具气泡、悬浮窗常用
    style |= wxSTAY_ON_TOP;       // 视需要添加

    return style;
}
```

构造函数示例：

```cpp
class RoundedFrame : public wxFrame
{
public:
    RoundedFrame(wxWindow* parent = nullptr)
        : wxFrame(parent, wxID_ANY, "",            // 无标题栏，title 可为空
                  wxDefaultPosition, wxSize(360, 200),
                  GetRoundedBorderlessStyle())
    {
        // 初始化布局
        // ... 创建 panel、sizer、控件等

        // 初次设置窗口形状
        UpdateShape();

        // 在大小变化时重新计算圆角矩形
        Bind(wxEVT_SIZE, &RoundedFrame::OnSize, this);
    }

private:
    void OnSize(wxSizeEvent& evt)
    {
        UpdateShape();
        evt.Skip();
    }

    void UpdateShape();
};
```

## 3. 使用 wxGraphicsPath 构造圆角矩形

`wxGraphicsPath` 在 `include/wx/graphics.h` 中定义，支持：
- `AddRoundedRectangle(x, y, w, h, radius)`；
- 或者 `MoveToPoint` + `AddArcToPoint` 手动构建圆角轮廓（`wxRichToolTipPopup` 中即是这样做）。

在无边框、整窗可用作内容区域的前提下，可以直接用窗口大小构造路径：

```cpp
void RoundedFrame::UpdateShape()
{
#if wxUSE_GRAPHICS_CONTEXT
    wxSize size = GetSize();   // 对于无边框 TLW，等同于内容大小
    if ( !size.IsFullySpecified() || size == wxSize(0, 0) )
        return;

    wxGraphicsRenderer* renderer = wxGraphicsRenderer::GetDefaultRenderer();
    if ( !renderer )
        return;

    wxGraphicsPath path = renderer->CreatePath();

    // 圆角半径可根据 DPI 或窗口大小自适应
    const wxDouble radius = FromDIP(12, this);   // 典型 8~16 像素

    // 这里不留额外内边距，让形状刚好贴着窗口边界
    path.AddRoundedRectangle(0, 0, size.x, size.y, radius);

    // 设置窗口形状
    SetShape(path);
#endif
}
```

要点：
- `SetShape(path)` 由 `wxNonOwnedWindow` 提供实现（见 `interface/wx/nonownedwnd.h`）：
  - MSW：在 `src/msw/nonownedwnd.cpp` 中通过 GDI+/`SetWindowRgn()` 应用形状；
  - GTK：在 `src/gtk/nonownedwnd.cpp` 中转换为掩码，调用 `gdk_window_shape_combine_region/mask()`。
- 使用 `AddRoundedRectangle()` 能在 MSW、X11 上得到较平滑的圆角轮廓；在像素级观察仍是离散的，但足够 UI 使用。

如果需要在圆角矩形中再添加“尖角提示”（类似气泡提示），可以参考 `wxRichToolTipPopup::UpdateTipShape()` 的做法：用若干 `AddLineToPoint` 连接气泡三角形与圆角矩形，并用 `AddArcToPoint` 绘制每个圆角，最后 `path.CloseSubpath()` 后 `SetShape(path)`。

## 4. 拖动与交互

圆角 + 无边框意味着没有系统标题栏，因此必须自行实现拖动、关闭等交互。方案与普通无边框窗口完全相同，例如：

```cpp
class RoundedFrame : public wxFrame
{
    // ... 省略构造
private:
    wxPoint m_dragDelta;

    void OnLeftDown(wxMouseEvent& evt)
    {
        CaptureMouse();
        wxPoint pos = ClientToScreen(evt.GetPosition());
        wxPoint origin = GetPosition();
        m_dragDelta = wxPoint(pos.x - origin.x, pos.y - origin.y);
    }

    void OnMouseMove(wxMouseEvent& evt)
    {
        if ( evt.Dragging() && evt.LeftIsDown() )
        {
            wxPoint pos = ClientToScreen(evt.GetPosition());
            Move(wxPoint(pos.x - m_dragDelta.x, pos.y - m_dragDelta.y));
        }
    }

    void OnLeftUp(wxMouseEvent& evt)
    {
        if ( HasCapture() )
            ReleaseMouse();
    }
};
```

对应事件绑定：

```cpp
Bind(wxEVT_LEFT_DOWN,  &RoundedFrame::OnLeftDown,  this);
Bind(wxEVT_MOTION,     &RoundedFrame::OnMouseMove, this);
Bind(wxEVT_LEFT_UP,    &RoundedFrame::OnLeftUp,    this);
// 关闭按钮可用右键、ESC 或自定义控件触发 Close()
```

这种实现方式在 Windows、GTK（X11/Wayland）上行为都一致。

## 5. 平台差异与 Wayland 注意事项

### 5.1 Windows（wxMSW）

- 边框/装饰：如《无边框窗口.md》所述，`wxBORDER_NONE` + 不使用 `wxCAPTION` / 系统按钮样式会映射到 Win32 的 `WS_POPUP` 类型窗口，天然无边框。（参见 `src/msw/toplevel.cpp` 中 `wxTopLevelWindowMSW::MSWGetStyle()`）。
- 形状：`SetShape(wxGraphicsPath)` 最终调用 `SetWindowRgn()`，在所有受支持的 Windows 版本上表现稳定。
- 性能：圆角区域本质上是非矩形区域裁剪，窗口重绘成本略高，但对普通 UI 影响不大。

### 5.2 Linux：wxGTK（X11 / Wayland）

- 无边框：`wxBORDER_NONE` / `wxNO_BORDER` 在 `src/gtk/toplevel.cpp` 中会触发 `gtk_window_set_decorated(..., false)`，在 X11 与 Wayland 下都能去掉窗口装饰。
- 形状（圆角）：
  - `SetShape(const wxGraphicsPath&)` 文档（`interface/wx/nonownedwnd.h`）明确：
    > 目前在 wxMSW、wxOSX/Cocoa、wxGTK（需要 X11 扩展）以及 wxQt 上工作。
  - GTK 实现使用 `gdk_window_shape_combine_region/mask()`，这依赖底层后端对“非矩形窗口”的支持：
    - 在 X11 + 合成器环境下通常是支持的；
    - 在 Wayland 原生后端上，各桌面/合成器未必支持窗口形状裁剪，行为可能是：
      - 直接忽略形状设置（窗口仍然是矩形）；
      - 或者仅在某些主题/配置下生效。

实际策略：
- 若要求“Linux 上一定是圆角”：
  - 推荐在部署或文档中注明：优先 / 推荐使用 X11 后端（例如设置环境变量 `GDK_BACKEND=x11`）。
- 若只要求“在支持的环境下有圆角效果”：
  - 可以直接使用本文方案，并在运行期用 `wxPlatformInfo` / 环境变量检测 Wayland，必要时禁用 `SetShape()` 以避免奇怪行为（例如拖动时重绘异常）。

## 6. 透明度与阴影（可选）

圆角无边框窗口通常还需要半透明背景和阴影：

- 透明度：
  - 使用 `wxTopLevelWindow::SetTransparent(alpha)`，可叠加在圆角形状上；
  - 必须在窗口 `Show()` 前完成（参考 `samples/shaped/SeeThroughFrame`）。

- 阴影：
  - wxWidgets 不统一管理窗口阴影，通常由平台/WM 负责；
  - 对于 Shaped 窗口，某些 WM 不会自动加阴影，需要自己在内容中画“假阴影”，例如在圆角矩形之外多一层稍大、稍透明的路径进行填充。

## 7. 推荐落地方案

1. 若已使用《无边框窗口.md》中的基类：
   - 在该基类上增加 `wxFRAME_SHAPED` 样式；
   - 实现一个虚函数 `UpdateShapeRoundedRect(radius)`，在其中用 `wxGraphicsPath::AddRoundedRectangle()` 调用 `SetShape()`；
   - 在 `OnSize` 中调用该函数即可。

2. 新项目直接使用本文 `RoundedFrame` 模板：
   - 复制 `GetRoundedBorderlessStyle()` + `UpdateShape()` + 拖动事件处理；
   - 在 Windows + X11 下即可得到圆角矩形无边框窗口；
   - 在 Wayland 环境中，根据实际测试决定是否保留 `SetShape()` 调用。

通过以上方式，可以在 wxWidgets 中以最小改动实现一个跨平台的圆角矩形无边框窗口，同时保持对现有窗口布局和事件体系的兼容。
