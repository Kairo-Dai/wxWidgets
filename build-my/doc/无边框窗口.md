# 无边框窗口

> 本文基于当前 wxWidgets 源码以及 `samples/shaped/shaped.cpp` 示例，总结在 Linux（X11/Wayland）和 Windows 上创建无边框顶层窗口的做法。

## 1. 概念与目标

- **矩形无边框窗口**：窗口仍是矩形，只是去掉了窗口管理器/系统提供的边框、标题栏和系统按钮。
- **Shaped（非矩形）窗口**：通过 `SetShape()` 把窗口裁成任意形状，天然不带系统边框。
- 本文里的“无边框窗口”包含上述两种，重点说明如何写一套 **跨平台 C++ 代码**，在 Linux（X11 + Wayland）和 Windows 上得到一致的行为。

相关源码参见：
- 顶层窗口基础：`include/wx/toplevel.h`、`src/gtk/toplevel.cpp`、`src/msw/toplevel.cpp`
- 非拥有窗口/形状支持：`include/wx/nonownedwnd.h`、`src/gtk/nonownedwnd.cpp`、`src/msw/nonownedwnd.cpp`
- 示例：`samples/shaped/shaped.cpp`

## 2. 关键样式与类

### 2.1 顶层窗口类

- `wxFrame`：最常用的顶层窗口类，缺省样式为 `wxDEFAULT_FRAME_STYLE`（带标题栏、边框、系统菜单等）。
- `wxTopLevelWindow`：`wxFrame` 的基类，负责把 wx 的样式翻译成平台原生样式。
- `wxNonOwnedWindow`：`wxTopLevelWindow` 和 `wxPopupWindow` 的共同基类，提供 `SetShape()` 等功能
  （文档见 `interface/wx/nonownedwnd.h`）。

### 2.2 布局相关样式

- `wxDEFAULT_FRAME_STYLE`
  - 定义见 `include/wx/toplevel.h`：
    ```cpp
    #define wxDEFAULT_FRAME_STYLE \
            (wxSYSTEM_MENU | \
             wxRESIZE_BORDER | \
             wxMINIMIZE_BOX | \
             wxMAXIMIZE_BOX | \
             wxCLOSE_BOX   | \
             wxCAPTION     | \
             wxCLIP_CHILDREN)
    ```
  - 这是 **有边框、有标题栏** 的普通主窗口样式；要无边框，就不能直接使用它。

- `wxBORDER_NONE` / `wxNO_BORDER`
  - `wxNO_BORDER` 是 `wxBORDER_NONE` 的别名（见 `interface/wx/defs.h`）。
  - 对顶层窗口来说，是“不要普通边框”的信号；各平台实现会进一步把它翻译成“不要窗口装饰”。

- `wxSIMPLE_BORDER`
  - 顶层窗口在 GTK 端被特殊处理：当样式中出现 `wxSIMPLE_BORDER` 或 `wxNO_BORDER` 时，GTK 端会调用
    `gtk_window_set_decorated(..., false)`，彻底关闭 WM 装饰（见 `src/gtk/toplevel.cpp`）。

- 其他常用组合位：
  - `wxFRAME_NO_TASKBAR`：窗口不在任务栏显示（Windows 独有语义，在 GTK 上映射为 `skip_taskbar` 提示）。
  - `wxSTAY_ON_TOP`：置顶窗口。
  - `wxFRAME_SHAPED`：允许使用 `SetShape()` 改变窗口形状（见 `interface/wx/frame.h` 与 `interface/wx/nonownedwnd.h`）。

## 3. 跨平台矩形无边框窗口

### 3.1 基本写法

核心思路：**不用 `wxDEFAULT_FRAME_STYLE`，从空样式开始，只按需叠加标志位**。

```cpp
class BorderlessFrame : public wxFrame
{
public:
    BorderlessFrame()
        : wxFrame(nullptr, wxID_ANY, "",          // 无标题栏，标题字符串无意义
                  wxDefaultPosition, wxSize(400, 300),
                  GetBorderlessStyle())
    {
        // 这里像普通 wxFrame 一样放控件、设置 sizer 即可
    }

    static long GetBorderlessStyle()
    {
        long style = 0;

        // 关键：表达“不要系统边框/标题栏”
        style |= wxBORDER_NONE;        // 或 wxNO_BORDER

        // 常见附加需求
        style |= wxFRAME_NO_TASKBAR;   // 可选：不在任务栏显示（splash / 工具条型窗口）
        style |= wxSTAY_ON_TOP;        // 可选：总在最前

        // 如果需要可调整大小而不出现标题栏，可以加上：
        // style |= wxRESIZE_BORDER;

        return style;
    }
};
```

说明：
- 不要写成 `wxDEFAULT_FRAME_STYLE & ~wxCAPTION` 之类的“减法”，
  因为不同平台上 `wxDEFAULT_FRAME_STYLE` 翻译到原生样式时规则很复杂。
- 从 `0` + `wxBORDER_NONE` 起步，平台实现会自动在 MSW/GTK 上创建无装饰窗口。

### 3.2 无标题栏后的拖动与关闭

去掉标题栏后，窗口不会自动支持拖动和右上角关闭，需要自己处理鼠标事件。

`samples/shaped/shaped.cpp` 中的 `ShapedFrame` 给出了一个参考实现（拖动逻辑在 `OnLeftDown` / `OnMouseMove` / `OnLeftUp` 中）：

```cpp
void ShapedFrame::OnLeftDown(wxMouseEvent& evt)
{
    CaptureMouse();
    wxPoint pos = ClientToScreen(evt.GetPosition());
    wxPoint origin = GetPosition();
    m_delta = wxPoint(pos.x - origin.x, pos.y - origin.y);
}

void ShapedFrame::OnMouseMove(wxMouseEvent& evt)
{
    if (evt.Dragging() && evt.LeftIsDown())
    {
        wxPoint pos = ClientToScreen(evt.GetPosition());
        Move(wxPoint(pos.x - m_delta.x, pos.y - m_delta.y));
    }
}

void ShapedFrame::OnLeftUp(wxMouseEvent& WXUNUSED(evt))
{
    if (HasCapture())
        ReleaseMouse();
}
```

实际项目中可直接复用这种写法，用某处点击关闭按钮（或右键菜单）来调用 `Close()`。

## 4. Linux：wxGTK（X11 / Wayland）上的无边框

### 4.1 样式到 GTK 的映射

在 `wxTopLevelWindowGTK::Create` 中（`src/gtk/toplevel.cpp`），可以看到样式如何转成 GTK/WM 装饰：

```cpp
if ( (style & wxSIMPLE_BORDER) || (style & wxNO_BORDER) )
{
    m_gdkDecor = 0;
    gtk_window_set_decorated(GTK_WINDOW(m_widget), false);
}
else // have border
{
    m_gdkDecor = GDK_DECOR_BORDER;
    if ( style & wxCAPTION )
        m_gdkDecor |= GDK_DECOR_TITLE;
    // ... 其他最小化、最大化、菜单、可调大小等修饰
}
```

结论：
- 只要在创建 `wxFrame` 时带上 `wxBORDER_NONE`（或 `wxSIMPLE_BORDER`），
  GTK 会直接把 `decorated` 设为 `false`，X11 和 Wayland 下都不再绘制任何窗口装饰。
- 这是本文 3.1 中 `GetBorderlessStyle()` 在 Linux 端生效的根本原因。

### 4.2 Shaped 窗口

Shaped 窗口通过 `wxFRAME_SHAPED` + `SetShape()` 实现：

1. 样式层（`include/wx/nonownedwnd.h`）要求：
   ```cpp
   // SetShape 要求窗口在创建时带有 wxFRAME_SHAPED
   wxCHECK_MSG(HasFlag(wxFRAME_SHAPED), false,
               "Shaped windows must be created with the wxFRAME_SHAPED style.");
   ```

2. GTK 具体实现（`src/gtk/nonownedwnd.cpp`）：
   - `DoSetRegionShape()` 内部调用 `gdk_window_shape_combine_region()`；
   - `DoSetPathShape()` 利用 `wxGraphicsPath` 生成掩码，然后在 `DoSetShape()` 中调用
     `gdk_window_shape_combine_region()` 或 `gdk_window_shape_combine_mask()`。

3. 示例代码（`samples/shaped/shaped.cpp` 中 `ShapedFrame::ShapedFrame`）：
   ```cpp
   ShapedFrame::ShapedFrame(wxFrame *parent)
       : wxFrame(parent, wxID_ANY, wxEmptyString,
                 wxDefaultPosition, wxSize(100, 100),
                 0
                 | wxFRAME_SHAPED
                 | wxSIMPLE_BORDER
                 | wxFRAME_NO_TASKBAR
                 | wxSTAY_ON_TOP)
   {
       m_shapeKind = Shape_Star;
       m_bmp = wxBitmap("star.png", wxBITMAP_TYPE_PNG);
       SetSize(wxSize(m_bmp.GetWidth(), m_bmp.GetHeight()));
       SetToolTip("Right-click to close, double click to cycle shape");
       SetWindowShape();     // 内部调用 SetShape(...)
   }

   void ShapedFrame::SetWindowShape()
   {
       switch ( m_shapeKind )
       {
           case Shape_Star:
               SetShape(wxRegion(m_bmp, *wxWHITE));
               break;
           // ... 其他形状（使用 wxGraphicsPath）
       }
   }
   ```

注意：
- `interface/wx/nonownedwnd.h` 文档中提到，`SetShape(const wxGraphicsPath&)`
  在 wxGTK 端“依赖 X11 的扩展”，因此 **在 Wayland 后端上不保证可用**。
- 实际上 GTK 下调用的是 `gdk_window_shape_combine_region/mask`，
  这些 API 在 Wayland 上的支持由 GTK 与合成器决定，行为可能因环境不同而不同。
- 如果需要在任意 Linux 桌面环境稳定工作，建议：
  - **矩形无边框** 使用 `wxBORDER_NONE`；
  - **复杂形状** 在项目中明确说明“X11 后端优先/推荐”。

## 5. Windows（wxMSW）上的无边框

### 5.1 样式到 Win32 的映射

在 `wxTopLevelWindowMSW::MSWGetStyle()` 中（`src/msw/toplevel.cpp`），
wx 的样式被翻译成 Win32 `WS_*` 标志。与边框相关的关键部分如下：

```cpp
WXDWORD msflags = wxWindow::MSWGetStyle(
                    (style & ~wxBORDER_MASK) | wxBORDER_NONE, exflags
                 ) & ~WS_CHILD & ~WS_VISIBLE;

// 边框与 caption
if ( (style & wxRESIZE_BORDER) && !IsAlwaysMaximized())
    msflags |= WS_THICKFRAME;
else if ( exflags && ((style & wxBORDER_DOUBLE) || (style & wxBORDER_RAISED)) )
    *exflags |= WS_EX_DLGMODALFRAME;
else if ( !(style & wxBORDER_NONE) )
    msflags |= WS_BORDER;
else
    msflags |= WS_POPUP;

if ( style & (wxCAPTION | wxMINIMIZE_BOX | wxMAXIMIZE_BOX | wxCLOSE_BOX) )
    msflags |= WS_CAPTION;
else
    msflags |= WS_POPUP;
```

含义：
- 当样式里带有 `wxBORDER_NONE`，且没有 `wxCAPTION`、最小化/最大化/关闭按钮时，
  会得到一个仅包含 `WS_POPUP` 的窗口——这是 Win32 下典型的 **无边框、无标题栏顶层窗口**。
- 如果再叠加 `wxRESIZE_BORDER`，对应加上 `WS_THICKFRAME`，可以得到 **无标题栏但可调整大小** 的窗口。

因此，前文 3.1 中的 `GetBorderlessStyle()` 同样在 Windows 生效。

### 5.2 Shaped 窗口

MSW 端的形状实现位于 `src/msw/nonownedwnd.cpp`：

- `DoSetRegionShape()`：
  - 把 `wxRegion` 底层的 HRGN 拷贝出来，
  - 调整坐标到整个窗口（非 client 区），
  - 调用 `::SetWindowRgn(hwnd, hrgn, TRUE)`。

- `DoSetPathShape()`：
  - 利用 GDI+ 的 `GraphicsPath` 生成区域，
  - 再调用 `SetShape(wxRegion(...))`，并在 `OnPaint` 中用 `wxGraphicsContext` 把形状边界描出来。

从调用端看，代码与 GTK 完全一致：

```cpp
frame = new wxFrame(parent, wxID_ANY, "",
                    wxDefaultPosition, wxSize(100, 100),
                    wxFRAME_SHAPED | wxBORDER_NONE | wxSTAY_ON_TOP);

// 使用位图或 wxGraphicsPath 描述形状
frame->SetShape(wxRegion(maskBmp, *wxWHITE));
// 或
wxGraphicsPath path = wxGraphicsRenderer::GetDefaultRenderer()->CreatePath();
path.AddCircle(...);
frame->SetShape(path);
```

由于 MSW 直接使用 `SetWindowRgn`，Shaped 窗口在 Windows 下 **既支持矩形无边框，也支持任意形状**，行为稳定。

## 6. 透明度与无边框窗口

无边框窗口经常需要半透明效果。wxWidgets 为所有顶层窗口提供统一接口：

- `bool wxTopLevelWindow::CanSetTransparent();`
- `bool wxTopLevelWindow::SetTransparent(wxByte alpha);`  // `alpha` 取值 0~255

示例仍可参考 `samples/shaped/SeeThroughFrame`（文件 `samples/shaped/shaped.cpp`）：

```cpp
void SeeThroughFrame::Create(wxWindow* parent)
{
    wxFrame::Create(parent, wxID_ANY, "Transparency test",
                    wxDefaultPosition, wxSize(300, 300),
                    wxDEFAULT_FRAME_STYLE | wxSTAY_ON_TOP);

    const int initialAlpha = wxALPHA_OPAQUE / 2;
    // ... 创建 slider 调整透明度

    // 注意：必须在 Show() 之前调用
    SetTransparent(initialAlpha);
}
```

平台实现要点：
- MSW：`src/msw/toplevel.cpp` 中通过 `WS_EX_LAYERED + SetLayeredWindowAttributes()` 实现。
- GTK：`src/gtk/toplevel.cpp` 中优先使用 RGBA visual / `gtk_widget_set_opacity()`；
  老版本 GTK + X11 下则通过 `_NET_WM_WINDOW_OPACITY` 属性。

这些与是否无边框无直接关系，可以自由组合使用。

## 7. 实际项目中的推荐做法

1. **矩形无边框（推荐方案）**
   - 创建 `wxFrame` 时：
     ```cpp
     long style = wxBORDER_NONE | wxFRAME_NO_TASKBAR | wxSTAY_ON_TOP;
     auto* frame = new wxFrame(nullptr, wxID_ANY, "", wxDefaultPosition,
                               wxSize(400, 300), style);
     ```
   - 结合鼠标事件实现拖动和关闭逻辑（可直接参考 `ShapedFrame` 的代码）。

2. **Shaped 特效窗口（需要兼容 Windows + X11）**
   - 创建时加上 `wxFRAME_SHAPED`：
     ```cpp
     long style = wxFRAME_SHAPED | wxBORDER_NONE | wxFRAME_NO_TASKBAR | wxSTAY_ON_TOP;
     ```
   - 使用位图或 `wxGraphicsPath` 调用 `SetShape()`。
   - 文档中注明：在 Linux/Wayland 环境下行为取决于 GTK/合成器，不保证所有组合下都生效。

3. **透明无边框叠加层**
   - 在 1 或 2 的基础上调用 `SetTransparent(alpha)`，
   - 注意在某些平台上 `CanSetTransparent()` 可能返回 `false`，需要做降级处理。

以上模式都已经在 wxWidgets 源码与 `samples/shaped` 中得到验证，
只要遵守“从空样式构造 + 显式添加 `wxBORDER_NONE` / `wxFRAME_SHAPED`”的原则，
即可在 Linux（X11/Wayland）和 Windows 上稳定创建无边框窗口。
